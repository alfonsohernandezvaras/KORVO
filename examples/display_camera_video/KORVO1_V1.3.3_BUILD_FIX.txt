KORVO1 V1.3.3 - ESP-IDF 6.1 / GCC 15 build fixes

Fixes found by the real V1.3.2 build:
1. SIP digest MD5 migrated from removed mbedtls/md5.h to ESP-IDF esp_rom_md5.h API.
2. korvo_audio_bridge.c now includes esp_check.h for ESP_RETURN_ON_ERROR.
3. Bluetooth and SIP copy_text() use bounded memcpy/strnlen instead of snprintf("%s") to avoid GCC 15 -Wformat-truncation errors.
4. main explicitly requires esp_rom.
5. Keeps the V1.3.2 global -Wno-error=stringop-truncation workaround for the ESP-IDF 6.1 Bluedroid source warning.

No changes to reciprocal-IP Gateway pairing, GPIO map, HMI architecture, access logic, or simulation.
