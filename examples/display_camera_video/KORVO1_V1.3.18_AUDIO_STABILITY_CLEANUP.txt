KORVO1 V1.3.18 - AUDIO / STABILITY / CLEANUP
Base: V1.3.17 SIP PSRAM FIX

- Visual LVGL black screensaver removed.
- Camera frame processing, motion calculation, health conditions and runtime camera watchdog intentionally preserved.
- HFP output volume retained on right edge.
- Added left-edge persistent microphone TX gain (0..100%).
- Added Web /intercom audio level controls for output and microphone gain.
- Added RTP RX/TX, dropped packets, MIC dropped and SCO underrun diagnostics to Web UI.
- SIP active-call sequence now announces active HFP call before requesting SCO.
- Active SIP/RTP call retries SCO every 1.5 s if SLC remains connected but SCO is down.
- Gateway heartbeat reduced: sys.ping every 15 s, sys.status only once on WS connect; dead timeout 45 s.
- Gateway manager/reconnect cadence and recovery logic preserved.
- SIP User-Agent and PROJECT_VER updated to 1.3.18.

NOT changed:
- camera/video/motion/watchdog functional chain
- face AI
- Gateway protocol / GPIO mapping
- Bluetooth pairing/supervisor architecture
- WAV alarm path
- SIP/RTP architecture
- SIP video (deferred until audio is stable)
