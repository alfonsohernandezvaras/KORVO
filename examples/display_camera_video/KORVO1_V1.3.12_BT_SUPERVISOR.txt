KORVO1 V1.3.12 - HFP SLC AUTO-CONNECT / CONNECTION SUPERVISOR

Base: V1.3.11 INTERNAL MEMORY FIX.

Changes:
- Pair/bond and HFP Service Level Connection are now displayed as separate states.
- After a successful Bluetooth authentication/bond, the supervisor establishes the real HFP SLC automatically.
- Persistent lightweight HFP supervisor runs from the existing 500 ms status task (no extra Bluetooth watchdog task/stack).
- If the paired HF/amplifier powers off or drops link, KORVO retries HFP SLC every 5 s.
- Stale CONNECTING attempts are released after 15 s and retried.
- Manual DISCONNECT suspends automatic reconnect until CONNECT/pair or Bluetooth power-on is requested again.
- Local touch Bluetooth screen now changes CONECTAR / CONECTANDO / DESCONECTAR dynamically.
- Web /intercom now changes CONNECT / CONNECTING / DISCONNECT dynamically.
- Device lists distinguish PAIR / CONNECT, CONNECT, CONNECTING and CONNECTED.
- Camera footer distinguishes BT ON, BT PAIR and BT CON:<peer>.
- SIP call state notifications also nudge the Bluetooth supervisor, but normal operation keeps HFP connected continuously so alarms are ready without an incoming call.

No changes to camera, Gateway pairing protocol, SIP signaling, RTP codec, alarm waveforms, SD layout, or access-control GPIO protocol.

IMPORTANT: source package prepared but not compiled in this environment. Build user-side with ESP-IDF 6.1.
