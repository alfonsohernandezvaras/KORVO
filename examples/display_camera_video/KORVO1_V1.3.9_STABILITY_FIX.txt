KORVO1 V1.3.9 - stability fix

Changes from V1.3.8:
- Runtime camera watchdog heartbeat is now updated on every real camera/video frame callback.
  It no longer depends on the heavier motion-percentage processing path.
- Bluetooth local full-screen UI is refreshed only while that screen is visible.
  The normal camera footer still receives Bluetooth state every 500 ms.
- Webserver V1.3.6 stack/heap fixes remain unchanged.
- Bluetooth local/remote pair UI from V1.3.8 remains unchanged.

Purpose:
Avoid false 10-second camera watchdog resets and unnecessary LVGL heap/task churn
while the Bluetooth panel is hidden.

Not compiled in ChatGPT container.
